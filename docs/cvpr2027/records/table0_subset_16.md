# 16-dataset working subset

Included datasets: CHASEDB1, CHCrack5k, CREMI, CrackTree200, DCA1, DRIVE, DeepCrack, FIVES, HRF, LES-AV, OCTA-500, ROAD, STARE, TopoMortar, WIRE, XCAD.

Excluded: CORN, TYRE, DeepGlobe, LEAF. This is a user-specified working subset; it is not a claim that the excluded datasets are outside the benchmark.
